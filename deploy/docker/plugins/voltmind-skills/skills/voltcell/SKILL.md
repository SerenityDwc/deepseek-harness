# VoltCell 电芯设计技能（知识驱动）

> **REQUIRED SUB-SKILL:** Use `voltmind-conventions` for 产物登记 / 需求澄清 / 进度显示 / 图表选型 / 产物数量与形态 约定。
> 本技能描述电芯设计领域内容 + 知识库增强；交互与产物约定见 voltmind-conventions。
> **跨 harness**：知识库增强依赖 DSH 的 VoltKnow MCP 工具（`mcp__voltknow__*`）；缺失时回退内置基准的规则计算（不阻断）。

## 用途

面向电芯设计工程师：从需求出发，**检索电芯知识库（wiki 实验卡片 + 原始文献）获得真实材料证据**，推荐材料体系与关键参数（带引用），再用 `voltcell_design` 计算验证，输出可追溯的设计方案。

## 输入参数（需求采集，10 项）

按 voltmind-conventions「需求澄清」一次一问，逐项确认（用户已明确不重复问）：

| # | 参数 | 单位 | 优先 |
|---|---|---|---|
| 1 | 容量 | Ah/mAh | ✅ |
| 2 | 重量上限 | g | ✅ |
| 3 | 能量目标 | Wh | ✅ |
| 4 | 体积/重量能量密度 | Wh/L、Wh/kg | ✅ |
| 5 | 标称/平台电压 | V | ✅ |
| 6 | 循环寿命 | 次 | ✅ |
| 7 | 尺寸 | 长×宽×厚 mm | ✅ |
| 8 | 安全性要求 | 安规/针刺/热箱等 | ✅ |
| 9 | 封装结构 | 软包/方壳/圆柱 | ✅ |
| 10 | 工作/存储温区 | ℃ | — |
| — | 其他（快充/成本/倍率） | — | 可选 |

**工程参数补齐**（用户不用提供，由知识库+默认值填）：配方配比/克容量/涂覆面密度/压实/N-P 比/隔膜/电解液注液系数/壳体等（对应设计 Know-how 41 项输入）。知识库（VoltKnow）查材料参数有则用（带引用）、无则用内置默认值（标注 `source: default`）。

## 执行流程（采集→补齐→推荐→计算→输出）

1. **需求采集**（按 conventions 一问一答，10 项，见上）。
2. **知识检索**（多源综合）：
   - `mcp__voltknow__wiki_search`：材料/设计方案/测试报告/工艺页（结构化实验卡片，4-Signal 重排）
   - `mcp__voltknow__hybrid_search`：原始文献（比容量/实测能量密度/循环寿命）
   - wiki 无命中自动回落文献；两源都无 → 回退内置基准并标注 `source: builtin`
3. **方案推荐**（两层，带引用）：
   - **体系级**：根据需求（容量/目标密度/应用场景）推荐化学体系与形态，给出知识库依据（如"NCM811 全电池 333 Wh/kg ← 10313365.pdf"）
   - **参数级**：比容量、电压平台、能量密度实测、循环寿命——每条附 `<kb doc="文件名" chunk_id="..." kb_id="..."/>` 引用
4. **工程参数补齐**：41 项设计输入（配方/极片/JR/装配/壳体）——知识库材料参数优先，内置默认值表兜底；每项标注 `knowledge|default`
5. **工程计算**：`voltcell_design`（v5 script.py）按设计 Know-how 公式——设计容量(目标+余量)→能量→重量(极片+隔膜+电解液+装配件)→能量密度→目标校验；`knowledge_params` 覆盖电压/循环
6. **校验合理性**：内置基准 + 知识库实测交叉验证；密度/重量未达目标给差距与优化方向
7. **输出方案 + 产物**（HTML+Excel 双产物，见下）

## 引用约定（双呈现）

- **行内标注**：推荐参数后紧跟 `<kb doc="文件名" chunk_id="..." kb_id="..."/>`（与 VoltKnow 返回一致），方案文字里可追溯
- **引用清单**：产物报告（`design_*.md/html`）末尾列「参考文献与数据来源」表：`参数 | 值 | 来源文档 | 类型(wiki/文献)`
- **无引用不推荐**：每条推荐参数必须有出处；知识库未覆盖时明说"内置基准，知识库未覆盖"

## 领域判断：合理性校验

- 内置基准（化学体系 × 形态系数）：LFP ~165 Wh/kg、NMC ~245、LMO ~150；pouch 0.92 / cylindrical 0.85 / prismatic 0.88。
- **知识库实测优先**：检索到实测能量密度（如 NCM811 333/414 Wh/kg）时用它替代内置基准校验（knowledge_params.density）。
- 超基准 ±15% 或与知识库实测偏差大时提示复核；未达目标能量密度给出差距与优化方向（提高容量 / 换体系 / 换形态）。

## 领域判断：方案输出要点

- 参数表：容量 / 电压 / 能量 / 能量密度 / 重量 / 循环寿命 + 参数来源（builtin/knowledge/default）。
- 材料要点：正极体系对应材料（LFP→磷酸铁锂、NMC→三元、LMO→锰酸锂）与隔膜/电解液/封装简述，**尽量引用知识库材料页**。
- 验证建议：循环寿命、热性能、安全验证清单，**参照知识库测试方法页**。
- 引用清单：见上「引用约定」。

## 产物（领域部分）——HTML + Excel 双产物

**HTML 设计报告为强制主件**：`design_<yyyyMMdd>_<chemistry>_<capacityAh>ah[<目标密度>].html`
- **必须**：单个自包含 HTML（离线可打开），纵向布局，图表内联（plotly/dsh-ui 数据同源），**引用可点击**（wiki 页用 dsh-ui link，见 conventions 第 9 节）。
- **分节与设计 Know-how 同构（完整参数集）**：概况（需求采集 10 项）→ 配方（正/负极）→ 极片（正/负极）→ J/R → 隔膜 → 电解液 → 铝塑膜 → 电池信息 → 壳体 → 计算结果（容量/电压/能量/重量/密度/寿命 + 目标校验）→ 引用清单。
- **参数集 = Know-how 全部 41 项输入（11 节）+ 全部计算输出**：每项输入标注来源（knowledge|default|user）；能算的算、算不了的呈现/标注待定（不编造）。

**Excel 设计表（同构，可下载再加工）**：`design_<yyyyMMdd>_<chemistry>_<capacityAh>ah[<目标密度>].xlsx`
- python+openpyxl 生成，sheet：需求与目标 / Cell信息 / **完整参数集（41 项，11 节，含来源列）** / 工程参数明细。
- 参数值与 HTML 报告一致；`voltmind_emit` 登记可点（office viewer 预览 / 下载）。

- 可选附加：`design_*.csv`（参数表数据）——按需，不替代双产物。
- 产物登记 / 数量 ≤6 / 形态自包含：全部按 voltmind-conventions 执行。
