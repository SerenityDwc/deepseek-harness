# 数据分析与可视化技能

> **REQUIRED SUB-SKILL:** Use `voltmind-conventions` for 产物登记 / 需求澄清 / 进度显示 / 图表选型 / 产物数量与形态 / 报告布局 约定。
> 本技能只描述数据分析领域内容；交互与产物约定见 voltmind-conventions（DSH 实现；跨 harness 时替换该技能）。

## 用途

面向实验与测试工程师：从 CSV/Excel 原始数据出发，产出**一份整体的 HTML 分析报告**（顶部结论 + 纵向图表），同时把清洗后数据与报告登记为可点产物，支撑决策与后续引用。

## 需求澄清（领域问题）

按 voltmind-conventions「需求澄清」一问一答，确认：

1. **数据来源**（必需）——文件路径或粘贴数据；Excel 多表时确认 sheet
2. **分析目标**（必需）——如"循环衰减趋势""分组对比""相关性分析"，决定图表选型
3. **关键字段/单位**（必要时）——列名含义、时间列、单位，缺失才问

## 执行流程

1. 澄清需求（数据来源 / 分析目标 / 关键字段）。
2. 读取数据：确认来源与字段语义；Excel 多表确认 sheet。
3. 清洗数据：处理缺失值、异常值、重复行，统一单位与时间格式；**记录每一步清洗动作**（报告"数据说明"节列出）。
4. 统计分析：均值/方差/极值/趋势，分组对比、相关性；**给结论**（数据支持什么、局限是什么）。
5. 生成整体 HTML 报告（布局/图表机制/产物形态按 voltmind-conventions 执行）。
6. 产物登记（按 conventions）。

## 报告内容（领域部分）

- **概况**：数据来源、样本数、关键条件（型号/批次/工况）。
- **结论摘要**：主要发现（数据支持什么）带编号 + 局限；结论可追溯（图表数据来自清洗/统计结果，数值一致）。
- **图表**：主趋势图最先，分布/对比/相关性随后，每图配一句结论性说明。
- **明细**：统计表 + 清洗说明。

## 产物（领域部分）

- 主件：整体 HTML 报告（命名 `analysis_<yyyyMMdd>_<key>.html`）。
- 数据：`analysis_<yyyyMMdd>_<key>.csv`（清洗后数据，供下载再加工）；xlsx 可选。
- 布局 / 数量 / 形态 / 登记：全部按 voltmind-conventions 执行。
