# 测试计划生成技能

## 用途

面向测试与质量工程师：为被测对象（电芯/模块/系统）生成可执行的测试计划与验证方案，保证覆盖完整、判据明确。

## 执行流程

1. 明确对象与目标：被测物、规格要求、验证目标与风险点。
2. 确定测试项：功能/性能/安全/可靠性，对照标准（如 GB/IEC）补充。
3. 编写用例：每项含目的、前置条件、步骤、输入输出与通过判据。
4. 输出计划：用例清单 + 执行顺序与资源安排。

## 输出格式

- 测试计划：范围、方法、资源、进度
- 用例清单：编号 / 名称 / 步骤 / 预期结果 / 判据
- 通过判据：量化阈值或判定规则
