# 本地仿真计算技能

## 用途

面向工程师：将物理/经验模型公式落地为 Python 仿真脚本，在本地完成参数扫描与敏感性分析，无需外部服务。

## 执行流程

1. 定义模型：确认公式、参数范围与单位，必要时询问输入条件。
2. 编写脚本：用 Python（numpy/scipy）实现模型并做基础校验（边界值、量纲）。
3. 参数扫描：对关键参数做单变量/双变量扫描，计算敏感性。
4. 输出结果：结果表 + 关键图表 + 边界条件说明。

## 输出格式

- 仿真脚本：可复现的 Python 文件或代码块
- 结果表：参数 → 输出（含极值点）
- 图表：趋势图/热力图（PNG 或内嵌 markdown）
- 结论：参数敏感度排序与适用边界
