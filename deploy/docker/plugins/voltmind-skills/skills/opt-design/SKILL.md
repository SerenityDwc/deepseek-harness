# 多参数优化设计技能

## 用途

面向设计工程师：在多个设计变量与约束下生成候选方案，通过对比评估选优，输出可决策的对比表与推荐方案。

## 执行流程

1. 明确变量与约束：设计变量、取值范围、硬约束与目标函数。
2. 生成候选组合：正交/网格/启发式采样，控制组合数量在可评估范围。
3. 评估打分：按目标函数与约束逐项评估，标注不满足项。
4. 对比优选：排序并输出推荐方案，附取舍理由与灵敏度提示。

## 输出格式

- 对比表：候选方案 × 指标（含约束满足标记）
- 推荐方案：最优组合 + 理由 + 次要备选
- 说明：关键假设与局限性
