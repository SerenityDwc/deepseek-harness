# 技术报告生成技能

## 用途

面向研发与项目管理：将数据、分析结果与试验结论组织为结构化的技术报告（docx/md），保证格式统一、结论可追溯。

## 执行流程

1. 收集素材：数据表、图表、分析结论与用户补充背景。
2. 组织大纲：摘要、背景/目标、方法、结果、讨论、结论与附录。
3. 撰写正文：结果与结论对应数据来源，图表编号引用一致。
4. 生成产物：按用户偏好输出 docx（含目录、页码）或 markdown。

## 输出格式

- 报告文件：`report_<日期>.docx` / `.md`
- 结构：摘要 → 背景 → 方法与数据 → 结果 → 结论与建议
- 附录：数据表、图表清单、复现说明
